# Amercharts

Amercharts is a small React chart library focused on modern dashboard visuals: soft gradients, restrained shadows, clean spacing, and elegant data-first tooltips.

This open source package includes the 15 Free charts. The Pro pack adds the full set of 96 chart components and lifetime updates.

## Install

```bash
npm install amercharts
```

## Usage

```tsx
import { Live3_BarChartGradient_DIV } from "amercharts";

export function DashboardCard() {
  return <Live3_BarChartGradient_DIV />;
}
```
